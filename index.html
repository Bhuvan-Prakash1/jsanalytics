Our Syllabus

Power BI Syllabus

  • Introduction, Installation, Data Types, Data Modeling
  • DAX Functions: Aggregation, Date/Time, Logical, Filter, Statistical, Text, Information, Time Intelligence
  • Power Query Editor: Data Source Connectivity, Transformation, Error Handling, Data Loading
  • Advanced: Column Tracking, Split/Choose Column, Join, Extract, Format, Append/Merge Query, Visualization, Dashboards, Power BI Service

Tableau Syllabus

  • Introduction, Interface, Data Types, Connections, Dimensions & Measures, Discrete & Continuous
  • Core Features: Groups, Sets, Parameters, Hierarchy, Filters, Functions, LOD, Bins
  • Visualization: Axis, Charts, Maps, Dashboards, Actions
  • Advanced: Data Modelling, Blending, Joins, Server/Online, RLS, Alerts, Metrics, Aggregate/Group Functions

SQL Syllabus

  • Basics: Introduction, Installation, Creating DB/Tables, Data Types, Operators
  • Functions: Case/Character Manipulation, Date, Null, Number, Aggregate/Group Functions
  • Advanced: Analytical Functions, Joins, Constraints, Set Operators
  • Views & Queries: View, Materialized View, Sub-Queries, Pseudo Columns, Commands

Python Syllabus

  • Basics: Introduction, Installation, Compilation vs Interpretation, Hello World, Variables, Data Types, Operators
  • Control Structures: Functions, Conditionals, Loops, Data Structures, Iteration Tools
  • Advanced: Regex, Packages, Exceptions, Lambda, Generators, Aggregate/Group Functions
  • OOP: Classes, Objects, Constructor, Inheritance, Encapsulation, Polymorphism, Libraries (NumPy, Pandas, Matplotlib)

Power App Syllabus

  • Getting Started: Introduction, Installation, Developer Environment, Variables
  • Collections & Components: Creating, Accessing, Manipulating, Iterating, Clearing, Canvas Apps, Model-Driven Apps, Data Sources, Controls
  • Expressions & Screens: Expressions, Screens, Data Integration
